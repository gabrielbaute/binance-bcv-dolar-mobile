# BnB-BCV: Mobile app

En este repositorio iremos subiendo la versión mobile para nuestro proyecto en [BnB-BCV](https://github.com/gabrielbaute/binance-bcv-dolar)

Los objetivos son:
- Crear un cliente en Android (y posiblemente en iOS)
- Cubrir todas las rutas de la API
- Permitir a futuro que cada quien registre su instancia de [BnB-BCV](https://github.com/gabrielbaute/binance-bcv-dolar) en caso de tenerla, o [trabajar por defecto con la nuestra](https://dolar-vzla.rafnixg.dev/)
